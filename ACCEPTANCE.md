# Acceptance tests: evidence

Spec section 12 lists the tests that say the build is done. This file gives the evidence for each, as of 19 October 2026. Tests named here run in `npm test` unless marked slow; browser checks were run in the app (Chromium, in the Claude desktop browser pane) and are recorded in NOTES.md.

| 2 | 10,000 random genomes per species all grow to maturity with no failure and no invalid numbers. | **Partly: species B run pending** | Species A: 10,000 passed after the last change to its simulation (`npm run test:slow`; commit `4d6bb7d`).
